# 🍸 Cocktailz

[![Angular](https://img.shields.io/badge/Angular-20-DD0031?logo=angular&logoColor=white)](https://angular.dev)  
Aplicación web para explorar, filtrar y visualizar cócteles.  
Construida con **Angular 20**, **Angular Material** y un sistema de **First Utilities** para mantener estilos reutilizables y consistentes.

---

## ✨ Características principales

- 🔍 Búsqueda de cócteles por nombre, categoría o ingredientes.  
- 📊 Tablas con datos alineados e imágenes optimizadas.  
- 📱 Diseño responsivo con Angular Material.  
- 🎨 Theming configurable y tokens de estilo centralizados.  
- ⚡ Manejo de estado global con **NgRx**.  
- 🧩 Componentes standalone de Angular para mayor modularidad.  

---

- [Node.js](https://nodejs.org/) **v18 o superior**  
- [Angular CLI](https://angular.dev/tools/cli) **20.2.2 o superior**
